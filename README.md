# Dropdown Menu & Image Carousel

A JavaScript project featuring a reusable dropdown menu and an image carousel with navigation controls.

# Features

Dropdown Menu

Reveals menu items on click or hover.

Menu items are hardcoded in HTML and shown/hidden with JavaScript.

Reusable logic for multiple dropdowns on the same page.

Encapsulated in a module for easy integration.

Image Carousel

Allows navigation through images using next and previous buttons.

Displays navigation dots that indicate the current slide.

# Installation & Setup

Prerequisites

Ensure you have Node.js installed.

Clone the Repository

git clone https://github.com/yourusername/dropdown-carousel.git
cd dropdown-carousel

# Install Dependencies

npm install

Start Development Server

npm run dev

Then, open http://localhost:8080 in your browser.
